## 📖 About

**Aman Music** ek simple aur fast Android music app hai. Ye meri apni **AMAN MUSIC API** se gaane laata hai. Hindi, Punjabi, Bollywood, Lofi, jo chahiye search karo aur turant play karo.

Koi ads nahi, koi login nahi. Bas music. 🎧

## 📥 Download APK

1. Is repo ka **[Actions](../../actions)** tab kholo.
2. Sabse upar wala ✅ green build kholo.
3. Neeche **Artifacts** mein **`aman-music-apk`** download karo.
4. Zip extract karo aur **`app-debug.apk`** install karo.

> ⚠️ Install karte waqt "Unknown sources" / "Install unknown apps" allow karna padega.

---

## 🚀 Pehli Baar Kaise Use Karein

1. App kholo.
2. Ek box aayega, usme apni **API key** daalo aur **Save** dabao.
3. Bas! Trending gaane load ho jayenge. 🎉

> 🔑 Key baad mein badalni ho to upar ⚙️ par tap karo.

## ⚙️ APK Khud Kaise Banta Hai

Is repo mein **koi bhi change push karo**. GitHub Actions apne aap:

1. Node.js aur Java set up karta hai
2. Capacitor se Android project banata hai
3. APK build karta hai (5–8 minute)
4. APK ko **Artifacts** mein daal deta hai

Manually chalana ho to: **Actions → Build APK → Run workflow**.
